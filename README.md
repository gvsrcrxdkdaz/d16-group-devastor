## Overview

D16 Group Devastor 2 is a three-band distortion unit that applies independent saturation and clipping to each frequency band, enabling precise multiband tone sculpting from gentle warmth to extreme destruction.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group Devastor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three Bands** | Independently process low, mid, and high frequency bands |
| **Six Distortion Types** | Soft clip, hard clip, fold, wrap, and other algorithms per band |
| **Crossover** | Variable crossover frequencies with linear-phase filtering |
| **Output Limiter** | Built-in limiter prevents output clipping after heavy distortion |
